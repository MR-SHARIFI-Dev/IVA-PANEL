# IVA Panel for Android

## فارسی

نسخهٔ Android را فقط از [GitHub Releases](../../../../releases) رسمی دانلود کنید. حداقل نسخهٔ پشتیبانی‌شده **Android 10 (API 29)** است.

| فایل فعلی | معماری | سازگاری |
|---|---|---|
| `app-universal-release.apk` | Universal | Android 10 و بالاتر |

قبل از نصب، SHA-256 را با `SHA256SUMS.txt` همان Release مقایسه کنید. اگر Android دربارهٔ نصب از منبع ناشناس هشدار داد، مطمئن شوید فایل از ریپوی رسمی آمده است؛ پس از نصب، مجوز نصب از آن منبع را دوباره خاموش کنید. APK رسمی باید با کلید انتشار IVA Team امضا شده باشد.

## English

Download Android builds only from the official [GitHub Releases](../../../../releases). The minimum supported version is **Android 10 (API 29)**. The current asset is `app-universal-release.apk`; architecture-specific builds may be added to future releases. Verify the SHA-256 value against the release's `SHA256SUMS.txt`. The official APK must be signed with IVA Team's release key.

## Русский

Загружайте Android-сборки только из официального раздела [GitHub Releases](../../../../releases). Минимальная поддерживаемая версия — **Android 10 (API 29)**. Текущий файл — `app-universal-release.apk`; отдельные сборки для архитектур могут появиться в будущих выпусках. Сверьте SHA-256 с `SHA256SUMS.txt`. Официальный APK должен быть подписан ключом выпуска IVA Team.
