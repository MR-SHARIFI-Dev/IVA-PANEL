# IVA Panel for Windows

## فارسی

نسخهٔ Windows را فقط از [GitHub Releases](../../../../releases) رسمی دانلود کنید. این برنامه **فقط برای Windows 64-bit (x64)** ارائه می‌شود؛ نسخهٔ ۳۲ بیتی یا ARM64 پشتیبانی نمی‌شود.

| فایل فعلی | کاربرد |
|---|---|
| `IVA-VPN-1.0.1-Setup.exe` | نصب‌کنندهٔ نسخهٔ 1.0.1 برای Windows x64 |

قبل از اجرا، SHA-256 را با `SHA256SUMS.txt` مقایسه کنید. فایل رسمی بهتر است دارای امضای دیجیتال IVA Team باشد. اگر SmartScreen هشدار داد، نام Publisher و هش فایل را بررسی کنید؛ هشدار را برای فایل ناشناخته نادیده نگیرید.

## English

Download Windows builds only from the official [GitHub Releases](../../../../releases). IVA VPN for Windows supports **64-bit x64 systems only**; 32-bit and ARM64 systems are not supported. The current asset is `IVA-VPN-1.0.1-Setup.exe`. Verify its SHA-256 value and digital publisher before running it. Do not bypass SmartScreen for an unknown or mismatched build.

## Русский

Загружайте Windows-сборки только из официального раздела [GitHub Releases](../../../../releases). IVA VPN поддерживает **только 64-битные системы x64**; 32-битные и ARM64-системы не поддерживаются. Текущий файл — `IVA-VPN-1.0.1-Setup.exe`. Перед запуском проверьте SHA-256 и цифрового издателя. Не обходите SmartScreen для неизвестного файла или несовпадающей контрольной суммы.
