# Contributing | مشارکت | Участие

## فارسی

این مخزن متن‌باز نیست و ارسال کد اختصاصی عمومی پذیرفته نمی‌شود. گزارش خطا، اصلاح ترجمه، بهبود مستندات و پیشنهادهای بدون اطلاعات محرمانه قابل بررسی هستند. قبل از Pull Request یک Issue باز کنید و محدودهٔ تغییر را هماهنگ کنید.

## English

This repository is not open source, and public contributions to proprietary code are not accepted. Privacy-safe bug reports, translation corrections, documentation improvements, and non-confidential suggestions may be reviewed. Open an Issue before a Pull Request to agree on scope.

## Русский

Репозиторий не является открытым исходным кодом, поэтому публичные изменения закрытого кода не принимаются. Можно предложить безопасные отчёты об ошибках, исправления переводов, улучшения документации и неконфиденциальные идеи. Перед Pull Request создайте Issue и согласуйте объём изменений.

## Rules

- Do not submit proprietary source or material without IVA Team authorization.
- Do not include tokens, passwords, personal data, private URLs, logs containing identifiers, signing keys, or third-party confidential content.
- Keep Persian, English, and Russian pages consistent where the change affects users.
- Do not replace the proprietary license with an open-source license.
- By submitting documentation or artwork, you confirm that you have the right to provide it and grant IVA Team permission to use it in this repository and related IVA Panel materials.
