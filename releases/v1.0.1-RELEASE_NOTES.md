# IVA Panel Apps v1.0.1

## فارسی

نسخهٔ رسمی اپلیکیشن‌های IVA برای Android و Windows.

### دانلودها

- **Android 10 به بالا:** `app-universal-release.apk`
- **Windows 64-bit x64:** `IVA-VPN-1.0.1-Setup.exe`

### نصب پنل

- نصب‌کنندهٔ وب: https://install.ivaworks.site/
- ربات نصب: https://t.me/IVAPANELBOT

قبل از نصب، SHA-256 فایل را با `SHA256SUMS.txt` مقایسه کنید. نسخهٔ ۳۲ بیتی Windows پشتیبانی نمی‌شود.

## English

Official IVA applications for Android and Windows.

- **Android 10 or later:** `app-universal-release.apk`
- **Windows 64-bit x64:** `IVA-VPN-1.0.1-Setup.exe`
- Web installer: https://install.ivaworks.site/
- Installation bot: https://t.me/IVAPANELBOT

Compare each file's SHA-256 value with `SHA256SUMS.txt` before installation. 32-bit Windows is not supported.
