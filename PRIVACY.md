# IVA Panel Privacy Policy

**Last updated: 21 August 2026**

[فارسی](#فارسی) · [English](#english) · [Русский](#русский)

## فارسی

### ۱. دامنهٔ سیاست

این سیاست، شیوهٔ پردازش اطلاعات در IVA Panel، اپلیکیشن‌های Android و Windows، نصب‌کنندهٔ وب، ربات‌های رسمی IVA، وب‌سایت مستندات و کانال‌های پشتیبانی را توضیح می‌دهد.

### ۲. معماری و عدم ذخیره‌سازی اطلاعات

- درخواست‌های نصب و API مستقیماً از دستگاه کاربر به Cloudflare ارسال می‌شوند.
- API Token از سرور، پایگاه داده، ربات یا Telegram متعلق به IVA عبور نمی‌کند و توسط IVA ذخیره نمی‌شود.
- IVA ایمیل Cloudflare، Account ID، API Token، آدرس یا رمز پنل، IP کاربر، شناسهٔ دستگاه، آمار استفاده یا لاگ فعالیت را جمع‌آوری یا نگهداری نمی‌کند.
- ربات‌های رسمی IVA پایگاه دادهٔ کاربری یا لاگ دائمی ایجاد نمی‌کنند.
- سایت‌های رسمی IVA به سامانهٔ تحلیل رفتار، تبلیغات یا رهگیری متصل نیستند و Cookie رهگیری ایجاد نمی‌کنند.
- سایت مستندات فقط زبان و پوستهٔ انتخابی را در حافظهٔ محلی مرورگر (`localStorage`) نگه می‌دارد. این تنظیمات از دستگاه کاربر خارج نمی‌شوند و از تنظیمات مرورگر قابل پاک‌کردن هستند.

### ۳. سرویس‌های شخص ثالث

Cloudflare، Telegram، GitHub و ارائه‌دهندهٔ میزبانی مستقل از IVA عمل می‌کنند و ممکن است طبق سیاست‌های خود اطلاعات فنی لازم برای ارائهٔ سرویس را پردازش کنند. IVA کنترل کاملی بر لاگ‌ها یا دورهٔ نگهداری زیرساخت شخص ثالث ندارد.

### ۴. پیام‌های پشتیبانی

اطلاعاتی که کاربر داوطلبانه از طریق ایمیل یا Telegram برای پشتیبانی ارسال می‌کند فقط برای پاسخ‌گویی استفاده می‌شود. کاربر نباید API Token، رمز، فایل Backup یا اطلاعات حساس واقعی را ارسال کند.

### ۵. حذف اطلاعات

چون IVA برای عملکرد پنل دادهٔ کاربری ذخیره نمی‌کند، پایگاه دادهٔ کاربری برای حذف وجود ندارد. برای درخواست حذف یک پیام پشتیبانی، با `info@ivaworks.site` تماس بگیرید؛ حذف اطلاعات نگهداری‌شده توسط سرویس‌های شخص ثالث تابع امکانات و سیاست همان سرویس است.

### ۶. امنیت و مسئولیت کاربر

از API Token محدود و موقت استفاده کنید، Global API Key را وارد نکنید و پس از نصب توکن را لغو یا تعویض کنید. مسئولیت نگهداری امن حساب Cloudflare، رمز پنل و فایل‌های Backup با کاربر است.

### ۷. سن کاربران

استفاده برای افراد ۱۸ سال به بالا مجاز است. افراد زیر ۱۸ سال فقط با اطلاع و اجازهٔ سرپرست قانونی می‌توانند از سرویس استفاده کنند.

### ۸. تغییرات و تماس

تغییرات مهم از طریق کانال رسمی IVA Works اعلام و تاریخ بالای این سند به‌روز می‌شود. پرسش‌های حریم خصوصی: `info@ivaworks.site`.

## English

### 1. Scope

This policy covers IVA Panel, the Android and Windows applications, the web installer, official IVA bots, the documentation website, and support channels.

### 2. Architecture and no IVA-side storage

- Installation and API requests are sent directly from the user's device to Cloudflare.
- The Cloudflare API Token is not relayed through an IVA server, database, bot, or Telegram and is not stored by IVA.
- IVA does not collect or retain Cloudflare email addresses, account IDs, API Tokens, panel addresses or passwords, user IP addresses, device identifiers, usage analytics, or activity logs.
- Official IVA bots do not maintain a user database or persistent activity logs.
- Official IVA websites use no behavioral analytics, advertising trackers, or tracking cookies.
- The documentation website stores only the selected language and color theme in browser `localStorage`. These preferences remain on the device and can be removed through browser settings.

### 3. Third-party services

Cloudflare, Telegram, GitHub, and the hosting provider operate independently and may process technical information required to provide their services under their own policies. IVA does not control all infrastructure logs or retention performed by third parties.

### 4. Support communications

Information voluntarily sent through email or Telegram is used only to answer the support request. Do not send live API Tokens, passwords, backup files, or other sensitive values.

### 5. Deletion

IVA does not maintain a user database for panel operation. To request deletion of a support message, contact `info@ivaworks.site`. Data held by third-party services is subject to the controls and policies of those services.

### 6. Security and user responsibility

Use a restricted and temporary API Token, never use a Global API Key, and revoke or rotate the token after installation. Users are responsible for securing their Cloudflare account, panel password, and backup files.

### 7. Age

The service is intended for users aged 18 or older. A person under 18 may use it only with the knowledge and permission of a legal guardian.

### 8. Changes and contact

Material changes will be announced through the official IVA Works channel and the date above will be updated. Privacy contact: `info@ivaworks.site`.

## Русский

### 1. Область действия

Политика распространяется на IVA Panel, приложения Android и Windows, веб-установщик, официальных ботов IVA, сайт документации и каналы поддержки.

### 2. Архитектура и отсутствие хранения в IVA

- Запросы установки и API отправляются напрямую с устройства пользователя в Cloudflare.
- API Token Cloudflare не проходит через сервер, базу данных, бота или Telegram IVA и не сохраняется IVA.
- IVA не собирает и не хранит адреса электронной почты Cloudflare, Account ID, API Token, адреса или пароли панели, IP-адреса пользователей, идентификаторы устройств, аналитику использования или журналы активности.
- Официальные боты IVA не ведут базу пользователей и постоянные журналы действий.
- Официальные сайты IVA не используют поведенческую аналитику, рекламные трекеры или отслеживающие Cookie.
- Сайт документации сохраняет только язык и тему в `localStorage` браузера. Эти настройки остаются на устройстве и удаляются через настройки браузера.

### 3. Сторонние сервисы

Cloudflare, Telegram, GitHub и хостинг-провайдер работают независимо и могут обрабатывать технические данные по собственным политикам. IVA не контролирует все журналы инфраструктуры и сроки хранения сторонних сервисов.

### 4. Обращения в поддержку

Информация, добровольно отправленная по электронной почте или через Telegram, используется только для ответа. Не отправляйте действующие API Token, пароли, резервные копии или другие секреты.

### 5. Удаление

IVA не ведёт пользовательскую базу для работы панели. Для удаления сообщения поддержки напишите на `info@ivaworks.site`. Данные сторонних сервисов удаляются по правилам соответствующего сервиса.

### 6. Безопасность и ответственность пользователя

Используйте ограниченный временный API Token, не используйте Global API Key и отзовите или замените токен после установки. Пользователь отвечает за безопасность аккаунта Cloudflare, пароля панели и резервных копий.

### 7. Возраст

Сервис предназначен для лиц от 18 лет. Пользователи младше 18 лет могут использовать его только с ведома и разрешения законного представителя.

### 8. Изменения и контакт

Существенные изменения публикуются в официальном канале IVA Works, а дата документа обновляется. Контакт по вопросам конфиденциальности: `info@ivaworks.site`.
