# IVA Panel Support

## فارسی

1. ابتدا [FAQ فارسی](docs/fa/FAQ.md) را بخوانید.
2. وضعیت شبکه را در [IVA Radar](https://net.ivaworks.site/) بررسی کنید.
3. برای خطای قابل بازتولید برنامه از Issue Template استفاده کنید.
4. برای مشکل نصب یا حساب به [@Ivaworkersup](https://t.me/Ivaworkersup) پیام دهید.
5. برای پرسش عمومی از [@IVAPANELCHAT](https://t.me/IVAPANELCHAT) یا [@IVA_Panel_group](https://t.me/IVA_Panel_group) استفاده کنید.

هنگام گزارش، نسخهٔ برنامه، Android/Windows، مدل دستگاه، متن دقیق خطا و مراحل بازتولید را بنویسید. توکن، رمز، ایمیل خصوصی یا اسکرین‌شات حاوی اطلاعات حساس نفرستید.

## English

Read the [English FAQ](docs/en/FAQ.md), check [IVA Radar](https://net.ivaworks.site/), use an Issue template for reproducible app defects, or contact [@Ivaworkersup](https://t.me/Ivaworkersup) for installation and account help. Include the app version, operating system, device model, exact error, and reproduction steps. Never include secrets or private account data.

## Русский

Прочитайте [FAQ на русском](docs/ru/FAQ.md), проверьте [IVA Radar](https://net.ivaworks.site/), используйте шаблон Issue для воспроизводимой ошибки или обратитесь к [@Ivaworkersup](https://t.me/Ivaworkersup). Укажите версию приложения, ОС, модель устройства, точный текст ошибки и шаги воспроизведения. Не добавляйте секреты или закрытые данные аккаунта.
