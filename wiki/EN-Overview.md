# IVA Panel overview

IVA Panel is a professional, integrated multi-location management panel powered by Cloudflare Workers. This Wiki is the official reference for installation, features, application downloads, security, privacy, and troubleshooting.

## Quick start

1. Read the [[installation guide|EN-Installation]].
2. Use only the [official web installer](https://install.ivaworks.site/) or [@IVAPANELBOT](https://t.me/IVAPANELBOT).
3. Download applications only from the [official GitHub Releases](https://github.com/MR-SHARIFI-Dev/IVA-PANEL/releases).
4. Check the [[FAQ|EN-FAQ]] and [[troubleshooting guide|EN-Downloads-and-Troubleshooting]] before requesting support.

## Highlights

- Integrated management of multiple locations
- One-click deployment on Cloudflare Workers
- Base64, Clash/Mihomo, sing-box, Loon, Surge, and Quantumult X subscriptions
- VLESS, Trojan, and Shadowsocks with multiple transports
- Health Check, Load Balancing, Failover, and Clean IP Scanner
- GeoIP/GeoSite routing, Domestic Bypass, IPv6, and NAT64
- WARP, WARP+, WoW, and Amnezia WARP
- Persian RTL dashboard, dark mode, panel logs, and JSON editor
- User quotas, expiration, TOTP, sessions, and Backup/Restore
- National Internet, Arvan CDN, and Google Apps Script relays in v3
- Dedicated Android 10+ and Windows x64 applications

See the complete [[Feature Matrix]].

## Privacy architecture

Cloudflare requests are sent directly from the user's device to Cloudflare. IVA stores no token, account email, user IP address, panel password, or activity log. See [[Architecture and data flow]].
