# Безопасность и поддержка

## Никогда не отправляйте

- Cloudflare API Token или Global API Key
- Пароль панели, TOTP или код восстановления
- UUID, ссылку подписки или полную конфигурацию
- Backup, Cookie аутентификации или файл закрытого ключа
- Неотредактированные снимки с IP-адресом, почтой или идентификатором

## Сообщение об уязвимости

Не публикуйте уязвимость в открытом Issue, Discussion, группе или канале. Используйте один из закрытых способов:

1. **Private Vulnerability Reporting** на вкладке Security репозитория
2. Электронная почта `info@ivaworks.site`

Хороший отчёт содержит затронутую версию и компонент, шаги воспроизведения, влияние на безопасность и возможное исправление. Не прикладывайте реальные пользовательские данные.

## Проверка выпусков

Загружайте только из GitHub Releases, сравнивайте SHA-256 и проверяйте подпись платформы. См. [[Release Information]].

## Действия при утечке

Если токен или пароль мог быть раскрыт:

1. Немедленно отзовите токен Cloudflare.
2. Измените пароль панели.
3. Закройте активные сеансы и замените TOTP/коды восстановления.
4. Проверьте настройки и Workers аккаунта Cloudflare.
5. Свяжитесь с поддержкой приватно, не публикуя секрет повторно.
