# دانلود و رفع مشکل

## دانلود رسمی

| پلتفرم | حداقل سیستم | فایل |
|---|---|---|
| Android | Android 10+ | `app-universal-release.apk` |
| Windows | Windows x64 | `IVA-VPN-1.0.1-Setup.exe` |

[باز کردن GitHub Releases](https://github.com/MR-SHARIFI-Dev/IVA-PANEL/releases)

## بررسی قبل از نصب

1. نام فایل و شمارهٔ نسخه را کنترل کنید.
2. SHA-256 را با [[Release Information]] مقایسه کنید.
3. در Android وضعیت امضای APK را بررسی کنید.
4. در Windows از **Properties → Digital Signatures** اعتبار ناشر را بررسی کنید.
5. اگر فایل امضا ندارد یا امضا نامعتبر است، آن را اجرا نکنید.

## نصب‌کننده پاسخ نمی‌دهد

- مرورگر را به آخرین نسخه به‌روزرسانی کنید.
- VPN/Proxy، DNS سفارشی یا افزونهٔ مسدودکننده را موقتاً بررسی کنید.
- ساعت و تاریخ دستگاه را خودکار کنید.
- از بازشدن `dash.cloudflare.com` مطمئن شوید.
- مجوزهای API Token و انقضای آن را بررسی کنید.
- توکن را در پیام پشتیبانی ارسال نکنید.

## پنل ساخته شد ولی باز نمی‌شود

- چند دقیقه برای انتشار Worker صبر کنید.
- آدرس را دقیقاً با `https://` باز کنید.
- تنظیمات DNS و Custom Domain را بررسی کنید.
- یک‌بار با شبکه یا DNS دیگری آزمایش کنید.
- وضعیت عمومی را در [IVA Network Intelligence](https://net.ivaworks.site/) ببینید.

## Android نصب نمی‌شود

- Android باید نسخهٔ ۱۰ یا بالاتر باشد.
- نسخهٔ قبلی با امضای متفاوت را حذف نکنید مگر Backup دارید.
- فضای خالی و اجازهٔ Install unknown apps را بررسی کنید.
- فقط APK رسمی را نصب کنید.

## Windows اجرا نمی‌شود

- سیستم باید ۶۴ بیتی باشد.
- امضای دیجیتال و SHA-256 را کنترل کنید.
- پیام SmartScreen را بدون تأیید ناشر نادیده نگیرید.
- خطا را همراه نسخهٔ Windows و متن دقیق خطا گزارش کنید؛ فایل خصوصی یا توکن نفرستید.

## اطلاعات مناسب برای گزارش خطا

- نسخهٔ Worker، Panel و Installer
- سیستم‌عامل و نسخهٔ آن
- مرحله‌ای که خطا رخ داده
- متن خطا یا تصویر سانسورشده
- زمان تقریبی خطا و ISP، در صورت مرتبط بودن

توکن، UUID، رمز، IP خصوصی، لینک اشتراک و Backup را حذف یا تار کنید.
