# حریم خصوصی و شرایط استفاده

## مالک و مسئول پروژه

مالک رسمی پروژه **IVA Team** است. ایمیل رسمی: `info@ivaworks.site`.

## داده‌هایی که IVA جمع‌آوری یا ذخیره نمی‌کند

- Cloudflare API Token و اطلاعات حساب
- IP کاربر، رمز پنل و تنظیمات خصوصی
- لاگ نصب یا فعالیت
- Analytics، تبلیغات رفتاری و Cookie رهگیری

درخواست نصب مستقیماً از دستگاه کاربر به Cloudflare می‌رود. سایت مستندات استاتیک و بدون بک‌اند است. اطلاعاتی که داوطلبانه برای پشتیبانی ارسال می‌کنید فقط برای پاسخ به همان درخواست استفاده می‌شود.

## سرویس‌های شخص ثالث

Cloudflare، GitHub، Telegram و میزبان دامنه تحت شرایط و سیاست‌های مستقل خودشان فعالیت می‌کنند. IVA کنترل‌کنندهٔ سیاست‌های آن‌ها نیست.

## سن مجاز

استفاده برای افراد ۱۸ سال به بالا یا با اجازهٔ سرپرست قانونی مجاز است.

## استفادهٔ مجاز

کاربر موظف است قوانین محل زندگی، شرایط Cloudflare و حقوق اشخاص ثالث را رعایت کند. استفاده برای ساخت انبوه حساب، دور زدن سهمیه، نفوذ، آسیب‌رسانی، فیشینگ، بدافزار یا نقض حقوق دیگران ممنوع است.

## مجوز اختصاصی

این پروژه متن‌باز نیست. دانلود یا استفاده از نسخه‌ها حق کپی، فروش، بازنشر، مهندسی معکوس، حذف علائم تجاری یا ساخت نسخهٔ مشتق ایجاد نمی‌کند.

## مسئولیت کاربر

حفاظت از حساب Cloudflare، Token، رمز، TOTP، Recovery Code، Backup و لینک‌های خصوصی بر عهدهٔ کاربر است. IVA اتصال دائمی، پینگ مشخص یا دسترس‌پذیری سرویس‌های شخص ثالث را تضمین نمی‌کند.
