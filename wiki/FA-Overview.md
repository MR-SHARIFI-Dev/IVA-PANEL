# IVA Panel | آیوا پنل

IVA Panel یک پنل حرفه‌ای و یکپارچه برای مدیریت چند لوکیشن بر بستر Cloudflare Workers است. این Wiki مرجع رسمی نصب، قابلیت‌ها، دانلود برنامه‌ها، امنیت و رفع خطای پروژه است.

## شروع سریع

1. [[پیش‌نیازها و مراحل نصب|FA-Installation]] را بخوانید.
2. فقط از [نصب‌کنندهٔ رسمی](https://install.ivaworks.site/) یا [@IVAPANELBOT](https://t.me/IVAPANELBOT) استفاده کنید.
3. برنامه‌ها را فقط از [GitHub Releases رسمی](https://github.com/MR-SHARIFI-Dev/IVA-PANEL/releases) دریافت کنید.
4. قبل از ارسال درخواست پشتیبانی، [[FAQ|FA-FAQ]] و [[رفع مشکل|FA-Downloads-and-Troubleshooting]] را بررسی کنید.

## امکانات اصلی

- مدیریت هم‌زمان چند لوکیشن
- استقرار یک‌کلیکی روی Cloudflare Workers
- لینک‌های اشتراک Base64، Clash/Mihomo، sing-box، Loon، Surge و Quantumult X
- VLESS، Trojan و Shadowsocks با transportهای گوناگون
- Health Check، Load Balancing، Failover و Clean IP Scanner
- مسیریابی GeoIP/GeoSite، Domestic Bypass، IPv6 و NAT64
- WARP، WARP+، WoW و Amnezia WARP
- پنل فارسی RTL، تم تاریک، لاگ محلی پنل و ویرایشگر JSON
- مدیریت کاربران، سهمیه، انقضا، TOTP، نشست‌ها و Backup/Restore
- Relay اینترنت ملی، CDN آروان و Google Apps Script در نسل v3
- اپلیکیشن Android 10+ و Windows x64

مقایسهٔ کامل: [[Feature Matrix]].

## وضعیت حریم خصوصی

در معماری فعلی، درخواست Cloudflare مستقیماً از دستگاه کاربر به Cloudflare می‌رود. IVA توکن، ایمیل حساب، IP، رمز پنل یا لاگ فعالیت را ذخیره نمی‌کند. جزئیات: [[Architecture and data flow]].
