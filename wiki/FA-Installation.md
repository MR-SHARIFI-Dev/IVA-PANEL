# راهنمای نصب IVA Panel

## پیش‌نیازها

- سن ۱۸ سال به بالا، یا اجازهٔ سرپرست قانونی
- حساب Cloudflare مطابق قوانین Cloudflare
- ایمیلی که به آن دسترسی دارید و می‌توانید تأییدش کنید
- مرورگر به‌روز
- نگهداری امن آدرس پنل و رمز عبور

> از ساخت انبوه حساب، دور زدن محدودیت سرویس‌دهنده یا استفاده از حساب شخص دیگر خودداری کنید.

## مرحله ۱ — ساخت API Token محدود

1. وارد داشبورد Cloudflare خود شوید.
2. بخش **My Profile → API Tokens** را باز کنید.
3. یک API Token با حداقل دسترسی لازم برای Worker بسازید.
4. تاریخ انقضای کوتاه انتخاب کنید، اگر این گزینه در دسترس است.
5. از **Global API Key** استفاده نکنید.

## مرحله ۲ — اجرای نصب‌کننده

یکی از مسیرهای رسمی را باز کنید:

- وب: https://install.ivaworks.site/
- ربات رسمی: https://t.me/IVAPANELBOT

توکن را فقط داخل رابط رسمی نصب وارد کنید؛ آن را به‌صورت پیام Telegram، Issue، گروه یا پیام پشتیبانی ارسال نکنید. درخواست مستقیماً از دستگاه شما به Cloudflare فرستاده می‌شود.

## مرحله ۳ — ساخت پنل

1. گزینهٔ ساخت پنل را انتخاب کنید.
2. منتظر تکمیل پاسخ Cloudflare بمانید و صفحه را نبندید.
3. آدرس پنل و رمز عبور نمایش‌داده‌شده را فوراً در Password Manager ذخیره کنید.
4. یک‌بار وارد پنل شوید و صحت عملکرد را بررسی کنید.

## مرحله ۴ — امن‌سازی بعد از نصب

1. API Token نصب را در Cloudflare لغو یا تعویض کنید.
2. رمز پیش‌فرض پنل را تغییر دهید.
3. TOTP و کدهای بازیابی را فعال و آفلاین نگهداری کنید.
4. از تنظیمات یک Backup رمزگذاری‌شده تهیه کنید.
5. هیچ فایل تنظیمات یا لینک خصوصی را عمومی نکنید.

## انتخاب کلاینت

- Android 10+: `app-universal-release.apk`
- Windows x64: `IVA-VPN-1.0.1-Setup.exe`
- کلاینت‌های دیگر: Clash/Mihomo، sing-box، Loon، Surge و Quantumult X با فرمت مربوط

## نصب با دامنه یا مسیر جایگزین

قابلیت‌هایی مانند اینترنت ملی، CDN آروان یا Google Apps Script به تنظیمات شبکه و نسخهٔ پنل وابسته‌اند. فعال‌بودن قابلیت تضمین نمی‌کند که در همهٔ ISPها اتصال یا کاهش پینگ ایجاد شود.

اگر نصب کامل نشد، [[دانلود و رفع مشکل|FA-Downloads-and-Troubleshooting]] را بخوانید.
