# قابلیت‌های IVA Panel

## اشتراک و کلاینت‌ها

- لینک اشتراک خودکار، Base64 و QR Code
- Clash/Mihomo، sing-box، Loon، Surge و Quantumult X
- تشخیص خودکار کلاینت و Mixed Auto
- لینک مستقیم VLESS، Trojan، Shadowsocks و Clash
- لینک اختصاصی کاربران با نام کاربری، کلید مخفی، سهمیه و انقضا

## شبکه و مسیریابی

- Load Balancing، Failover، Health Check و Proxy Fallback
- GeoIP، GeoSite، Domestic Bypass و قوانین سفارشی
- IPv6، NAT64، WARP، WARP+، WoW و Amnezia WARP
- Clean Cloudflare IP Scanner و بهینه‌سازی IP به تفکیک ISP
- WebSocket، gRPC، XHTTP، Port-spread و Multi-transport
- Relay اینترنت ملی، CDN آروان و Google Apps Script در v3

## DNS و محافظت

- DoH، DNS encryption، Local DNS و Anti-Sanction DNS
- Load Balance/Failover/Caching DNS
- AdBlock، PornBlock، Malware، Phishing و Cryptominer blocking
- QUIC blocking و Fake DNS

## پنل مدیریت

- رابط فارسی RTL و واکنش‌گرا
- حالت ساده و پیشرفته، تم تاریک و تور راهنما
- JSON Config Editor، Log Viewer و Reset Config
- نمودار ترافیک، مدیریت کاربران و آمار ناوگان
- تغییر رمز، TOTP، Recovery Codes، محدودیت ورود و مدیریت نشست
- Backup/Restore کامل و مهاجرت KV به D1

## اتوماسیون

- مدیریت و Notification از طریق Telegram
- API مدیریت متمرکز، اعلان همگانی و Heartbeat
- ویزارد `/install` و استقرار یک‌کلیکی

برای مقایسهٔ دقیق v1، v2 و v3 صفحهٔ [[Feature Matrix]] را ببینید.

> نتیجهٔ عملی قابلیت‌های شبکه به ISP، وضعیت اینترنت، محدودیت‌های Cloudflare، دامنه و تنظیمات کاربر وابسته است و تضمین دائمی اتصال یا کاهش پینگ نیست.
