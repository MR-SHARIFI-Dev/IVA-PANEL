## Notes

- Availability means the capability exists in that generation; actual behavior may depend on configuration, Cloudflare quotas, upstream services, network conditions, and provider policies.
- Relay and route-optimization features may improve a suitable path but cannot guarantee lower latency or continuous connectivity in every network condition.
- Security-sensitive values such as API Tokens, authentication cookies, TOTP recovery codes, user secrets, and backup files must never be committed to this repository or posted publicly.
