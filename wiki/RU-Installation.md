# Установка IVA Panel

## Требования

- Возраст от 18 лет или разрешение законного представителя
- Аккаунт Cloudflare, используемый в соответствии с условиями Cloudflare
- Доступный вам подтверждённый адрес электронной почты
- Современный браузер
- Безопасное место для хранения адреса панели и пароля

> Не создавайте аккаунты массово, не обходите лимиты провайдера и не используйте чужой аккаунт без разрешения.

## Шаг 1 — Создайте ограниченный API Token

1. Войдите в Cloudflare Dashboard.
2. Откройте **My Profile → API Tokens**.
3. Создайте токен только с разрешениями, необходимыми для установки Worker.
4. По возможности задайте короткий срок действия.
5. Не используйте **Global API Key**.

## Шаг 2 — Откройте официальный установщик

- Веб-установщик: https://install.ivaworks.site/
- Официальный бот: https://t.me/IVAPANELBOT

Вводите токен только в официальном интерфейсе установки. Никогда не отправляйте его сообщением в Telegram, GitHub Issue, группу или поддержку. Запрос Cloudflare отправляется напрямую с вашего устройства в Cloudflare.

## Шаг 3 — Создайте панель

1. Выберите создание панели.
2. Не закрывайте интерфейс до завершения ответа Cloudflare.
3. Сохраните адрес панели и пароль в менеджере паролей.
4. Выполните вход и проверьте работу панели.

## Шаг 4 — Защитите установку

1. Отзовите или замените установочный токен в Cloudflare.
2. Измените пароль панели.
3. Включите TOTP и храните коды восстановления офлайн.
4. Создайте зашифрованную резервную копию настроек.
5. Не публикуйте закрытые конфигурации или ссылки подписки.

## Клиенты

- Android 10+: `app-universal-release.apk`
- Windows x64: `IVA-VPN-1.0.1-Setup.exe`
- Другие клиенты: Clash/Mihomo, sing-box, Loon, Surge и Quantumult X

National Internet, Arvan CDN и Google Apps Script зависят от версии панели и состояния сети. Наличие функции не гарантирует соединение или меньшую задержку у каждого провайдера.

Если установка не завершилась, см. [[Загрузки и устранение проблем|RU-Downloads-and-Troubleshooting]].
