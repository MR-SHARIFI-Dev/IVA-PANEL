از حساب Cloudflare تا پنل فعال در چند مرحله

نصب از وب‌سایت یا ربات رسمی انجام می‌شود. از API Token محدود استفاده کنید و هرگز Global API Key، رمز یا فایل Backup را در فضای عمومی نفرستید.

باز کردن نصب‌کننده ربات نصب پنل
  1. 1

    حساب را تأیید کنید

    یک حساب Cloudflare با ایمیلی که به آن دسترسی دارید بسازید.

  2. 2

    توکن محدود بسازید

    فقط حداقل دسترسی لازم را به API Token بدهید.

  3. 3

    پنل را ایجاد کنید

    توکن را فقط در وب‌سایت یا ربات رسمی وارد کنید.

  4. 4

    دسترسی را امن کنید

    آدرس و رمز را ذخیره و توکن نصب را لغو یا تعویض کنید.
