# فعال‌سازی سایت IVA Panel با GitHub Pages

سایت رسمی پروژه داخل پوشهٔ `docs/` همین ریپو قرار دارد و بدون سرور جداگانه از GitHub Pages منتشر می‌شود.

## قبل از شروع

- فایل‌های بستهٔ سایت را با همان ساختار پوشه‌ها در ریپو آپلود و Commit کنید.
- مطمئن شوید `docs/index.html` و `docs/.nojekyll` داخل شاخهٔ `main` وجود دارند.
- هیچ Token، رمز یا فایل تنظیمات خصوصی را داخل پوشهٔ سایت قرار ندهید.

## فعال‌سازی قدم‌به‌قدم

1. وارد صفحهٔ ریپوی IVA Panel در GitHub شوید.
2. بالای صفحه روی **Settings** بزنید.
3. از ستون سمت چپ وارد **Pages** شوید.
4. در بخش **Build and deployment**، گزینهٔ **Source** را روی **Deploy from a branch** بگذارید.
5. در قسمت Branch، شاخهٔ **main** و پوشهٔ **/docs** را انتخاب کنید.
6. روی **Save** بزنید.
7. چند دقیقه صبر کنید و صفحه را Refresh کنید تا لینک سایت نمایش داده شود.

آدرس معمول سایت به این شکل است:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
```

## اتصال سایت به صفحهٔ اصلی ریپو

1. در صفحهٔ اصلی ریپو، کنار بخش **About** روی آیکون چرخ‌دنده بزنید.
2. آدرس GitHub Pages را در فیلد **Website** وارد کنید.
3. گزینهٔ **Use your GitHub Pages website** را در صورت نمایش فعال کنید.
4. توضیح پیشنهادی را قرار دهید:

```text
Professional multi-location panel powered by Cloudflare Workers.
```

## بروزرسانی سایت

برای بروزرسانی، فقط فایل‌های تغییرکرده داخل `docs/` را Commit کنید. GitHub Pages نسخهٔ جدید را خودکار منتشر می‌کند.

## اگر سایت باز نشد

- بررسی کنید Source دقیقاً روی `main /docs` باشد.
- وجود فایل `docs/index.html` را بررسی کنید.
- در تب **Actions** نتیجهٔ فرایند Pages را ببینید.
- اگر ریپو Private است، مطمئن شوید پلن GitHub شما از Pages برای ریپوی خصوصی پشتیبانی می‌کند.
- انتشار اولیه ممکن است چند دقیقه طول بکشد.

## دامنهٔ اختصاصی

اگر بعداً دامنهٔ اختصاصی خواستید، ابتدا DNS را تنظیم کنید و سپس دامنه را در **Settings → Pages → Custom domain** وارد کنید. تا قبل از مشخص‌شدن دامنه، فایل `CNAME` نسازید.
