## معرفی و شرایط استفاده

### IVA Panel چیست؟

IVA Panel یک پنل مدیریتی رایگان و مولتی‌لوکیشن است که بر بستر **Cloudflare Workers** اجرا می‌شود و مدیریت سرویس‌ها، کاربران و لوکیشن‌های مختلف را از یک رابط یکپارچه ساده‌تر می‌کند.

### آیا سورس پروژه عمومی است؟

خیر. این ریپو مرکز رسمی مستندات، دانلود و انتشار نسخه‌هاست؛ کد منبع اختصاصی IVA Panel منتشر نمی‌شود. فایل‌ها، نام و نشان تجاری تحت [مجوز اختصاصی پروژه](../../LICENSE.md) هستند.

### آیا IVA Panel رایگان است؟

بله، استفاده از خود پنل رایگان است. هزینهٔ احتمالی دامنه، سرویس جانبی یا زیرساخت شخص ثالث جداست و توسط ارائه‌دهندهٔ مربوط تعیین می‌شود.

### آیا برای خود پنل VPS لازم است؟

خیر. خود پنل روی Cloudflare Workers اجرا می‌شود و برای اجرای آن به VPS جداگانه نیاز ندارید. سرویس‌ها یا زیرساخت‌هایی که از طریق پنل مدیریت می‌شوند ممکن است نیازهای مستقل داشته باشند.

### چه زبان‌هایی پشتیبانی می‌شوند؟

مستندات رسمی ریپو به فارسی، انگلیسی و روسی ارائه شده‌اند. پشتیبانی زبان رابط محصول ممکن است با نسخهٔ برنامه تغییر کند؛ توضیحات هر Release را بررسی کنید.

## نصب و امنیت

### نصب پنل چطور انجام می‌شود؟

از [نصب‌کنندهٔ رسمی وب](https://install.ivaworks.site/) یا ربات [@IVAPANELBOT](https://t.me/IVAPANELBOT) استفاده کنید. خلاصهٔ مراحل: ساخت و تأیید حساب Cloudflare، ساخت API Token محدود، ارسال توکن فقط به نصب‌کنندهٔ رسمی، ساخت پنل و ذخیرهٔ امن آدرس و رمز. جزئیات در [راهنمای نصب](INSTALLATION.md) آمده است.

### برای نصب دانش Linux یا SSH لازم است؟

خیر. نصب‌کنندهٔ یک‌کلیکی برای استفادهٔ معمول نیازی به Linux، SSH یا مدیریت دستی سرور ندارد. دانش فنی فقط برای تنظیمات پیشرفته یا عیب‌یابی مفید است.

### API Token چه تفاوتی با Global API Key دارد؟

API Token را می‌توان با حداقل دسترسی لازم و زمان استفادهٔ محدود ساخت؛ Global API Key دسترسی بسیار گسترده‌تری دارد. برای نصب از **Global API Key استفاده نکنید** و توکن را فقط در مسیرهای رسمی وارد کنید.

### بعد از نصب با توکن Cloudflare چه کنم؟

پس از اطمینان از فعال بودن پنل، توکن نصب را در داشبورد Cloudflare لغو یا تعویض کنید؛ مگر اینکه مستندات نسخه صریحاً ادامهٔ دسترسی را لازم بداند. توکن را در Issue، گروه یا اسکرین‌شات منتشر نکنید.

### آیا می‌توانم با ایمیل موقت ثبت‌نام کنم؟

استفاده از ایمیلی که به آن دسترسی پایدار و قانونی دارید توصیه می‌شود تا تأیید حساب و بازیابی دسترسی ممکن باشد. قوانین Cloudflare و هر سرویس ایمیل را رعایت کنید؛ IVA Team مسئول از دست رفتن حساب یا نقض شرایط سرویس‌های شخص ثالث نیست.

### آیا خطای 1101 وجود دارد؟

طراحی و نصب رسمی IVA Panel برای جلوگیری از خطاهای رایج Worker آماده شده است، اما هیچ نرم‌افزاری در همهٔ شرایط بدون خطا نیست. اگر Error 1101 دیدید، وضعیت [رادار](https://net.ivaworks.site/)، تنظیمات Worker و نسخهٔ نصب را بررسی و با اطلاعات غیرحساس گزارش کنید.

## قابلیت‌ها و مدیریت

### آیا Multi-Location پشتیبانی می‌شود؟

بله. IVA Panel برای مدیریت چند لوکیشن و زیرساخت مختلف از یک پنل یکپارچه طراحی شده است. ظرفیت واقعی به سرویس‌ها و منابع متصل بستگی دارد.

### تعداد کاربران نامحدود است؟

پنل محدودیت نرم‌افزاری ثابتی برای تعداد کاربر اعلام نمی‌کند، اما **Unlimited Users به معنی Unlimited Traffic نیست**. ظرفیت عملی به سهمیه‌ها، منابع، Worker، مسیر شبکه و سرویس‌های زیرساختی وابسته است.

### Backup و Restore دارد؟

بله. قابلیت **Full Backup / Full Restore** برای پشتیبان‌گیری از داده‌ها و تنظیمات و بازیابی آن‌ها در نظر گرفته شده است. فایل پشتیبان را رمزگذاری و خارج از دستگاه اصلی نگهداری کنید.

### آیا می‌توانم پنل را مهاجرت دهم؟

بله. ابتدا Backup کامل بگیرید، در محیط مقصد نسخهٔ سازگار را نصب کنید و سپس Restore را انجام دهید. قبل از حذف محیط قبلی، صحت کاربران، تنظیمات و اتصال‌ها را آزمایش کنید.

### آیا پنل در مرورگر موبایل کار می‌کند؟

بله. رابط پنل واکنش‌گراست و از مرورگر موبایل قابل مدیریت است. برای تجربهٔ اتصال روی دستگاه نیز اپلیکیشن Android ارائه می‌شود.

### مدیریت از Telegram ممکن است؟

بله. ربات رسمی برای نصب و بخش‌هایی از مدیریت در دسترس است. فقط از [@IVAPANELBOT](https://t.me/IVAPANELBOT) استفاده کنید و نام کاربری ربات را قبل از ارسال اطلاعات بررسی کنید.

### Relayهای Google، ArvanCloud و National Internet چه هستند؟

این‌ها مسیرهای ارتباطی جایگزین‌اند که در نسخه‌ها و شرایط پشتیبانی‌شده می‌توانند به بهبود مسیر یا حفظ دسترسی کمک کنند. نتیجه به وضعیت شبکه، سلامت Relay، تنظیمات و قوانین ارائه‌دهندگان وابسته است؛ هیچ Relay اتصال صددرصدی را تضمین نمی‌کند.

## اپلیکیشن‌ها و دانلود

### حداقل نسخهٔ Android چیست؟

اپلیکیشن رسمی برای **Android 10 و بالاتر** ارائه می‌شود. برای بیشتر کاربران فایل `app-universal-release.apk` مناسب است؛ فایل‌های معماری‌محور فقط زمانی استفاده شوند که معماری دستگاه را دقیق می‌دانید.

### نسخهٔ Windows برای چه سیستم‌هایی است؟

نسخهٔ رسمی Windows فقط برای **Windows 64-bit (x64)** منتشر می‌شود و نسخهٔ ۳۲ بیتی ارائه نمی‌شود.

### فایل برنامه را از کجا دانلود کنم؟

فقط از بخش [GitHub Releases](../../../releases) همین ریپو یا لینک رسمی اعلام‌شده در کانال [@PANEL_ivaworks](https://t.me/PANEL_ivaworks) دانلود کنید. فایل APK یا EXE را از کانال‌ها و سایت‌های ناشناس نگیرید.

### چطور اصالت فایل دانلودی را بررسی کنم؟

نام فایل، نسخه و مقدار SHA-256 را با فایل checksum همان Release مقایسه کنید. راهنمای Android و Windows و اسکریپت‌های بررسی در پوشهٔ `scripts/` قرار دارند.

## شبکه، مصرف و پایداری

### آیا IVA Panel برای استفادهٔ روزمره مناسب است؟

برای مرور وب، پیام‌رسانی، شبکه‌های اجتماعی، دانلود و استفادهٔ عمومی طراحی شده است. تجربهٔ نهایی به کیفیت اینترنت، مسیر انتخابی و زیرساخت شما بستگی دارد.

### آیا برای Gaming مناسب است؟

برای استفادهٔ عمومی قابل استفاده است، اما برای بازی سنگین یا رقابتی تضمین نمی‌شود. Ping، Jitter و Packet Loss بیشتر از خود پنل تحت تأثیر مسیر و وضعیت شبکه هستند.

### Request چیست و محدودیت روزانه چقدر است؟

Request یک درخواست ارتباطی میان Client و Service است و با حجم ترافیک یکسان نیست. سقف ثابتی برای همهٔ نصب‌ها وجود ندارد؛ سهمیه‌های Cloudflare، پیکربندی Worker، Relay و سرویس زیرساختی تعیین‌کننده‌اند.

### آیا مصرف زیاد باعث محدودیت یا Ban می‌شود؟

خود پنل به‌تنهایی باعث Ban نمی‌شود، اما ارائه‌دهندگان زیرساخت قوانین و سهمیه‌های خود را دارند. ترافیک غیرعادی، سوءاستفاده یا نقض شرایط سرویس می‌تواند به محدودیت حساب منجر شود.

### رادار اینترنت چه چیزی نشان می‌دهد؟

[IVA Network Intelligence](https://net.ivaworks.site/) وضعیت سرویس‌ها، تست‌های شبکه، تأخیر و اختلال‌های قابل مشاهده را نمایش می‌دهد. رادار ابزار تشخیصی است و تضمین‌کنندهٔ وضعیت همهٔ اپراتورها و مسیرها نیست.

## پشتیبانی

### قبل از ثبت مشکل چه چیزهایی آماده کنم؟

نسخهٔ پنل یا اپ، سیستم‌عامل، مدل دستگاه، زمان رخداد، متن دقیق خطا و مراحل بازتولید را بنویسید. وضعیت رادار و آخرین Release را نیز بررسی کنید.

### چه اطلاعاتی را هرگز منتشر نکنم؟

Cloudflare Token، Global API Key، رمز پنل، فایل Backup، کوکی، ایمیل خصوصی، شناسهٔ حساب و اسکرین‌شات دارای IP یا اطلاعات شخصی را عمومی نکنید.
