سیاست حریم خصوصی IVA Panel

آخرین به‌روزرسانی: ۳۰ مرداد ۱۴۰۵ / 21 August 2026

دامنه

این سیاست IVA Panel، اپلیکیشن‌های Android و Windows، نصب‌کنندهٔ وب، ربات‌های رسمی، سایت مستندات و پشتیبانی را پوشش می‌دهد.

معماری و عدم ذخیره‌سازی

  • درخواست نصب و API مستقیماً از دستگاه کاربر به Cloudflare ارسال می‌شود.
  • API Token از سرور، پایگاه داده، ربات یا Telegram متعلق به IVA عبور نمی‌کند و توسط IVA ذخیره نمی‌شود.
  • IVA ایمیل Cloudflare، Account ID، توکن، آدرس یا رمز پنل، IP، شناسهٔ دستگاه، آمار استفاده و لاگ فعالیت را جمع‌آوری یا نگهداری نمی‌کند.
  • ربات‌های IVA پایگاه دادهٔ کاربری یا لاگ دائمی ندارند.
  • سایت‌های IVA از تحلیل رفتار، تبلیغات و Cookie رهگیری استفاده نمی‌کنند.

تنظیمات محلی

سایت مستندات فقط زبان و پوسته را در localStorage مرورگر ذخیره می‌کند. این تنظیمات از دستگاه خارج نمی‌شوند.

شخص ثالث

Cloudflare، Telegram، GitHub و میزبان وب ممکن است طبق سیاست‌های خود اطلاعات فنی لازم برای ارائهٔ سرویس را پردازش کنند. IVA کنترل کاملی بر لاگ‌های زیرساخت آن‌ها ندارد.

پشتیبانی و حذف

اطلاعات داوطلبانهٔ پیام پشتیبانی فقط برای پاسخ استفاده می‌شود. چون IVA پایگاه دادهٔ کاربری ندارد، دادهٔ پنل برای حذف وجود ندارد. برای حذف پیام پشتیبانی به info@ivaworks.site پیام دهید.

سن و امنیت

استفاده برای ۱۸ سال به بالا یا با اجازهٔ سرپرست قانونی است. از API Token محدود استفاده و پس از نصب آن را لغو یا تعویض کنید.

IVA Panel Privacy Policy

Last updated: 21 August 2026

Scope

This policy covers IVA Panel, the Android and Windows applications, the web installer, official bots, the documentation website, and support.

Architecture and no IVA-side storage

  • Installation and API requests are sent directly from the user's device to Cloudflare.
  • The API Token is not relayed through or stored by an IVA server, database, bot, or Telegram.
  • IVA does not collect or retain Cloudflare email addresses, Account IDs, tokens, panel addresses or passwords, user IP addresses, device identifiers, analytics, or activity logs.
  • IVA bots maintain no user database or persistent activity logs.
  • IVA websites use no behavioral analytics, advertising trackers, or tracking cookies.

Local preferences

The documentation site stores only language and theme preferences in browser localStorage. They remain on the device.

Third parties

Cloudflare, Telegram, GitHub, and the web host may process technical data under their own policies. IVA does not control all third-party infrastructure logs.

Support and deletion

Voluntary support messages are used only to answer the request. IVA keeps no panel user database. To request deletion of a support message, contact info@ivaworks.site.

Age and security

The service is for users aged 18 or older, or with permission from a legal guardian. Use a restricted token and revoke or rotate it after installation.

Политика конфиденциальности IVA Panel

Обновлено: 21 августа 2026 г.

Область действия

Политика охватывает IVA Panel, приложения Android и Windows, веб-установщик, официальных ботов, сайт документации и поддержку.

Архитектура и отсутствие хранения

  • Запросы установки и API отправляются напрямую с устройства пользователя в Cloudflare.
  • API Token не проходит через сервер, базу, бота или Telegram IVA и не сохраняется IVA.
  • IVA не собирает и не хранит почту Cloudflare, Account ID, токены, адреса или пароли панели, IP, идентификаторы устройств, аналитику или журналы активности.
  • Боты IVA не ведут пользовательскую базу или постоянные журналы.
  • Сайты IVA не используют поведенческую аналитику, рекламные трекеры или отслеживающие Cookie.

Локальные настройки

Сайт документации хранит только язык и тему в localStorage браузера. Эти данные остаются на устройстве.

Сторонние сервисы

Cloudflare, Telegram, GitHub и хостинг могут обрабатывать технические данные по собственным политикам. IVA не контролирует все журналы их инфраструктуры.

Поддержка и удаление

Добровольно отправленные сообщения используются только для ответа. IVA не ведёт базу пользователей панели. Для удаления сообщения напишите на info@ivaworks.site.

Возраст и безопасность

Сервис предназначен для лиц от 18 лет либо используется с разрешения законного представителя. Используйте ограниченный токен и отзовите или замените его после установки.
