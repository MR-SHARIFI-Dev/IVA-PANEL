مرکز امنیت IVA Panel

آخرین به‌روزرسانی: 21 August 2026

توکن Cloudflare

  • فقط API Token محدود و ترجیحاً زمان‌دار بسازید.
  • Global API Key، رمز حساب، رمز پنل و Backup را ارسال نکنید.
  • پس از نصب، توکن را لغو یا تعویض کنید.
  • توکن در معماری IVA مستقیماً به Cloudflare ارسال و توسط IVA ذخیره نمی‌شود.

اصالت فایل‌ها

فایل را فقط از GitHub Releases رسمی دانلود و SHA-256 را بررسی کنید. اثر انگشت گواهی Android در صفحهٔ دانلود منتشر شده است. در Windows، تب Digital Signatures باید ناشر معتبر را نشان دهد؛ در غیر این صورت فایل را اجرا نکنید.

گزارش آسیب‌پذیری

آسیب‌پذیری را در Issue عمومی، گروه یا کانال منتشر نکنید. از بخش Security ریپوی رسمی گزینهٔ Report a vulnerability را بزنید یا بدون ارسال Secret به info@ivaworks.site پیام دهید.

اطلاعات گزارش

نسخه، سیستم‌عامل، مراحل بازتولید، اثر امنیتی و راه تماس را بنویسید. از داده و حساب آزمایشی استفاده کنید.

IVA Panel Security Center

Last updated: 21 August 2026

Cloudflare token

  • Create a restricted, preferably expiring API Token.
  • Never send a Global API Key, account password, panel password, or backup.
  • Revoke or rotate the token after installation.
  • Under IVA's architecture, the token is sent directly to Cloudflare and is not stored by IVA.

Release integrity

Download only from official GitHub Releases and verify SHA-256. The Android certificate fingerprint is published on the downloads page. On Windows, Digital Signatures must show a valid publisher; do not run a file with no valid signature.

Private reporting

Do not disclose a vulnerability in a public Issue, group, or channel. Use Security → Report a vulnerability in the official repository or email info@ivaworks.site without live secrets.

Report contents

Include the affected version, operating system, reproduction steps, security impact, and a contact method. Use test values and accounts.

Центр безопасности IVA Panel

Обновлено: 21 августа 2026 г.

Токен Cloudflare

  • Создавайте ограниченный и, по возможности, временный API Token.
  • Не отправляйте Global API Key, пароль аккаунта, пароль панели или резервную копию.
  • Отзовите или замените токен после установки.
  • В архитектуре IVA токен отправляется напрямую в Cloudflare и не сохраняется IVA.

Проверка выпуска

Загружайте только из официального GitHub Releases и проверяйте SHA-256. Отпечаток Android-сертификата опубликован на странице загрузок. В Windows раздел Digital Signatures должен показывать действительного издателя; не запускайте файл без действительной подписи.

Приватный отчёт

Не публикуйте уязвимость в Issue, группе или канале. Используйте Security → Report a vulnerability в официальном репозитории или напишите на info@ivaworks.site без действующих секретов.

Содержание отчёта

Укажите версию, ОС, шаги воспроизведения, влияние и контакт. Используйте тестовые данные.
