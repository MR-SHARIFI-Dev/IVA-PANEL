# Установка IVA Panel

[فارسی](../fa/INSTALLATION.md) · [English](../en/INSTALLATION.md) · [Русский](INSTALLATION.md)

В этом документе описан официальный процесс установки IVA Panel. Используйте только официальные ссылки из [README](../../README.ru.md).

## Что потребуется

- Аккаунт Cloudflare с подтверждённой и доступной вам электронной почтой.
- Доступ к официальному боту [@IVAPANELBOT](https://t.me/IVAPANELBOT).
- Надёжное место для хранения пароля панели.

## 1. Создание аккаунта Cloudflare

Зарегистрируйтесь на официальном сайте Cloudflare и подтвердите адрес электронной почты. Если вы используете [@IVAmailbot](https://t.me/IVAmailbot) для получения проектного адреса, продолжайте только при наличии доступа к письму подтверждения и при соблюдении условий Cloudflare и применимого законодательства. Не создавайте аккаунты массово, не обходите ограничения и не злоупотребляйте сервисом.

## 2. Создание ограниченного API Token

1. Войдите в панель Cloudflare.
2. Откройте **My Profile → API Tokens**.
3. Нажмите **Create Token**, затем **Create Custom Token**.
4. Назовите токен, например `IVA Panel Installer`.
5. Для базового развёртывания Worker обычно достаточно:
   - Account → **Account Settings: Read**
   - Account → **Workers Scripts: Edit**
6. Добавляйте **Workers KV Storage: Edit**, **Workers R2 Storage: Edit** или Zone → **Workers Routes: Edit** только если установщик действительно использует эти ресурсы.
7. Ограничьте ресурсы требуемым аккаунтом или зоной.
8. По возможности задайте срок действия.
9. Проверьте сводку, создайте токен и временно сохраните его. Значение показывается только один раз.

Официальная документация: [Create API token](https://developers.cloudflare.com/fundamentals/api/get-started/create-token/) и [API token permissions](https://developers.cloudflare.com/fundamentals/api/reference/permissions/).

> Не используйте Global API Key. Не публикуйте токен на скриншотах, в Issues, группах или сообщениях незнакомым людям.

## 3. Создание панели

1. Проверьте точное имя бота: **@IVAPANELBOT**.
2. Запустите бота и выберите создание панели.
3. Вводите токен только в официальном интерфейсе, открытом ботом; не отправляйте токен сообщением Telegram.
4. Дождитесь завершения развёртывания.
5. Сохраните адрес панели и пароль в менеджере паролей или другом защищённом месте.
6. Откройте панель и проверьте вход.

### Установка через сайт

Откройте [install.ivaworks.site](https://install.ivaworks.site/), внимательно проверьте адрес и следуйте инструкциям. Запросы установки отправляются напрямую с устройства в Cloudflare; токен не проходит через сервер, базу данных или Telegram IVA и не сохраняется ими. Если сайт недоступен, начните официальный процесс через [@IVAPANELBOT](https://t.me/IVAPANELBOT).

Полное описание архитектуры и отсутствия хранения приведено в [Политике конфиденциальности](../../PRIVACY.md).

## 4. Удаление лишнего доступа

После успешной установки вернитесь в API Tokens и **отзовите** установочный токен. Если он нужен для обновлений, оставьте минимальные права и регулярно заменяйте его.

## 5. Установка приложения

1. Откройте [Releases](../../../../releases).
2. Загружайте файлы только из официального репозитория.
3. Сравните SHA-256 файла с `SHA256SUMS.txt` выпуска.
4. Следуйте [инструкции Android](../../apps/android/README.md) или [инструкции Windows](../../apps/windows/README.md).

Текущая совместимость: **Android 10 и новее** и **только Windows 64-bit x64**.

## Решение проблем

- Сначала прочитайте [FAQ на русском](FAQ.md).
- Проверьте сеть в [IVA Radar](https://net.ivaworks.site/).
- Если проблема осталась, обратитесь к [@Ivaworkersup](https://t.me/Ivaworkersup); не отправляйте токен или пароль.
