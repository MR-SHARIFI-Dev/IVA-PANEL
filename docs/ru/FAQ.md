## Обзор и условия

### Что такое IVA Panel?

IVA Panel — бесплатная мультилокационная панель управления на базе **Cloudflare Workers**. Она объединяет управление сервисами, пользователями и несколькими локациями в одном интерфейсе.

### Исходный код опубликован?

Нет. Этот репозиторий является официальным центром документации, загрузок и выпусков; проприетарный исходный код IVA Panel не публикуется. Файлы, бренд и оригинальные материалы защищены [проприетарной лицензией](../../LICENSE.md).

### IVA Panel бесплатная?

Сама панель бесплатна. Домены, сторонние сервисы и внешняя инфраструктура могут иметь отдельную стоимость, установленную их поставщиками.

### Нужен ли VPS для самой панели?

Нет. Панель работает на Cloudflare Workers и не требует отдельного VPS. У сервисов и инфраструктуры, которыми вы управляете через панель, могут быть собственные требования.

### Какие языки поддерживаются?

Документация репозитория доступна на персидском, английском и русском языках. Набор языков интерфейса может меняться между версиями — проверяйте примечания к установленному выпуску.

## Установка и безопасность

### Как установить IVA Panel?

Используйте [официальный веб-установщик](https://install.ivaworks.site/) или [@IVAPANELBOT](https://t.me/IVAPANELBOT). Кратко: создайте и подтвердите аккаунт Cloudflare, создайте ограниченный API Token, передайте его только официальному установщику, создайте панель и безопасно сохраните адрес и пароль. См. [инструкцию](INSTALLATION.md).

### Нужны ли знания Linux или SSH?

Нет. Для обычной установки в один клик не требуются Linux, SSH или ручное администрирование сервера. Технические знания полезны только для расширенной настройки и диагностики.

### Почему API Token, а не Global API Key?

API Token можно ограничить минимальными разрешениями. Global API Key имеет значительно более широкий доступ. **Не используйте Global API Key для установки** и вводите токен только в официальных сервисах IVA.

### Что делать с токеном после установки?

После проверки работы панели отзовите или замените установочный токен в Cloudflare, если документация вашей версии прямо не требует сохранить доступ. Никогда не публикуйте токен в Issue, чате или скриншоте.

### Можно использовать временную почту?

Используйте адрес, к которому у вас есть законный и долгосрочный доступ, чтобы сохранить возможность подтверждения и восстановления аккаунта. Соблюдайте правила Cloudflare и почтового провайдера. IVA Team не отвечает за потерянные аккаунты или нарушение правил сторонних сервисов.

### Ошибка 1101 полностью исключена?

Официальная установка снижает риск распространённых ошибок конфигурации Worker, но ни одно ПО не работает без ошибок во всех средах. При Error 1101 проверьте [сетевой радар](https://net.ivaworks.site/), конфигурацию Worker и версию, затем передайте только несекретные данные диагностики.

## Функции и управление

### Поддерживается Multi-Location?

Да. IVA Panel предназначена для управления несколькими локациями и точками инфраструктуры из одной панели. Практическая ёмкость зависит от подключённых сервисов и ресурсов.

### Количество пользователей не ограничено?

Панель не заявляет фиксированного программного лимита пользователей, но **Unlimited Users не означает Unlimited Traffic**. Реальная ёмкость зависит от квот, ресурсов, Workers, сетевых маршрутов и внешних сервисов.

### Есть Backup и Restore?

Да. **Full Backup / Full Restore** предназначены для сохранения и восстановления данных и настроек. Шифруйте резервные копии и храните их отдельно от основного устройства.

### Можно перенести панель в новое окружение?

Да. Создайте полную резервную копию, установите совместимую версию в новом окружении и выполните Restore. Перед удалением старой среды проверьте пользователей, настройки и подключения.

### Панель работает в мобильном браузере?

Да. Адаптивный интерфейс позволяет управлять панелью с телефона. Для подключения на устройстве также доступно приложение Android.

### Можно управлять через Telegram?

Да. Официальная автоматизация Telegram поддерживает установку и отдельные операции управления. Используйте только [@IVAPANELBOT](https://t.me/IVAPANELBOT) и проверяйте имя бота перед передачей информации.

### Что такое Google, ArvanCloud и National Internet Relay?

Это альтернативные маршруты соединения, которые в поддерживаемых версиях и сетевых условиях могут улучшить маршрут или помочь сохранить доступ. Результат зависит от сети, состояния Relay, настроек и правил провайдеров; ни один Relay не гарантирует 100% соединение.

## Приложения и загрузки

### Какая минимальная версия Android?

Официальное приложение требует **Android 10 или новее**. Для большинства устройств рекомендуется `app-universal-release.apk`. APK для конкретной архитектуры используйте только тогда, когда точно знаете архитектуру устройства.

### Какие версии Windows поддерживаются?

Официальное приложение выпускается только для **64-битной Windows (x64)**. 32-битной сборки нет.

### Откуда загружать приложения?

Только из [GitHub Releases](../../../releases) этого репозитория или по официальной ссылке из канала [@PANEL_ivaworks](https://t.me/PANEL_ivaworks). Не загружайте APK или EXE с неизвестных зеркал.

### Как проверить загруженный файл?

Сравните имя, версию и SHA-256 с файлом контрольных сумм того же Release. Инструкции для платформ и скрипты проверки находятся в репозитории.

## Сеть, использование и стабильность

### Подходит ли IVA Panel для повседневного использования?

Панель рассчитана на браузер, сообщения, социальные сети, загрузки и обычную работу в интернете. Фактическое качество зависит от соединения, маршрута и вашей инфраструктуры.

### Подходит ли она для игр?

Для общего использования — да, но тяжёлые и соревновательные игры не гарантируются. Ping, jitter и packet loss в первую очередь зависят от маршрутизации и состояния сети, а не от панели.

### Что такое Request и каков дневной лимит?

Request — коммуникационный запрос между клиентом и сервисом; он не равен объёму трафика. Единого лимита для всех установок нет. Ёмкость определяется квотами Cloudflare, настройками Worker, Relay и внешней инфраструктурой.

### Может ли высокая нагрузка привести к ограничениям или бану?

Сама панель не вызывает бан, но поставщики инфраструктуры применяют собственные квоты и правила допустимого использования. Аномальный трафик, злоупотребление или нарушение правил могут привести к ограничению аккаунта.

### Что показывает IVA Network Radar?

[IVA Network Intelligence](https://net.ivaworks.site/) показывает наблюдаемый статус сервисов, сетевые тесты, задержку и сбои. Это инструмент диагностики, который не гарантирует состояние каждого оператора или маршрута.
