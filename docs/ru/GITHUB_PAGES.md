# Публикация сайта IVA Panel через GitHub Pages

Сайт проекта находится в папке `docs/` этого репозитория и публикуется без отдельного сервера.

## Включение GitHub Pages

1. Загрузите пакет сайта с сохранением структуры папок и создайте Commit.
2. Откройте **Settings** репозитория.
3. Выберите **Pages** в левом меню.
4. В разделе **Build and deployment** установите **Source → Deploy from a branch**.
5. Выберите ветку **main** и папку **/docs**.
6. Нажмите **Save** и подождите несколько минут.

Стандартный адрес:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
```

Добавьте полученный адрес в поле **About → Website** репозитория. Новые Commit в папке `docs/` будут публиковаться автоматически.

При ошибке 404 проверьте наличие `docs/index.html`, источник `main /docs` и результат Pages в разделе **Actions**.

Не создавайте файл `CNAME`, пока собственный домен и DNS ещё не настроены.
